Conveyor Drive

## Projektni Zadatak

Dizajn i proračun kompaktnog reduktora s čeonim zupčanicima za laboratorijski transporter.

- **Snaga:** 250 W
- **Prijenosni omjer:** 4.095 (Target: 4:1)
- **Modul:** 2 mm
- **Osni razmak:** 80.00 mm

## Struktura Projekta

├── 01_Proračuni/ # Izvještaji iz Solid Edge-a, Excel/Python izračuni
├── 02_Modeli/ # Solid Edge datoteke (.par, .asm)
│ ├── Parts/ # Zasebni dijelovi (Pinion, Gear, Shaft, Housing)
│ └── Assembly/ # Glavni sklopovi
├── 03_Proizvodnja/ # Tehnički crteži (.dft), DXF za laser, STL za 3D print
├── 04_Programi/ # Python kod za Digital Twin / GUI
├── 05_Dokumentacija/ # Slike rendera, PDF s objašnjenjem projekta, Datasheets
├── .gitignore # Datoteka koja govori GitHubu što da ignorira
└── README.md # Glavna prezentacijska stranica projekta
